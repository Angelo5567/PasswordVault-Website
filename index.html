Gestione delle password senza account obbligatori, interfacce inutilmente complicate o dipendenza da un servizio cloud.

🔐

Vault cifrato

Le credenziali vengono conservate nel vault protetto dell'app e non in chiaro.

⚡

Password Generator

Genera password robuste scegliendo lunghezza, lettere, numeri e simboli.

🛡

Auto-Lock

Blocca automaticamente il vault dopo un periodo di inattività configurabile.

Built around privacy.

PasswordVault è stato progettato con un approccio locale: il vault non dipende da un server remoto per funzionare.

PBKDF2 + SHA-256

La Master Password viene utilizzata per derivare la chiave di cifratura tramite PBKDF2.

Fernet

Il contenuto del vault viene cifrato prima di essere scritto sul disco.

Local-first

I dati del vault vengono mantenuti localmente sul dispositivo dell'utente.
